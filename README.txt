# Birthday Gift Website — GitHub Pages

## Upload
Upload EVERYTHING in this folder directly into the ROOT of your GitHub repository.

The repository must show `index.html`, `style.css`, `script.js`, `images/`, `video/`, and `music/` at the same level.

## GitHub Pages
Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Password
`birthday123`

## Media
Keep these exact filenames and lowercase folder names. GitHub Pages is case-sensitive.

Images: `images/photo1.jpeg`, `photo2.jpeg`, `photo3.jpeg`, `gallery1.jpeg` through `gallery6.jpeg`
Videos: `video/surprise1.mp4`, `surprise2.mp4`, `surprise3.mp4`
Music: `music/birthday-song.mp3`

Music cannot reliably autoplay with sound in modern browsers. Tap the music button once to start it.
